# Glossary

One name per idea. Screens should use the term in the first column.

| Term | Means | Do not also say |
| --- | --- | --- |
| Improve this plan | The question flow that fills a missing fact | Improve the books, when you mean that flow |
| Improve the books | The account, bill, and property editors | Dashboard |
| Cash home | The standing sentence and free-cash screen | Ledger |
| Free cash | Liquid money minus what is reserved | Leftover, in new copy |
| Hired date | The month a goal looks reachable | Retirement date, unless the goal is Retire early |
| Realistic | The default scenario | Expected, typical |
| Extra toward loans | Surplus sent to debt | Avalanche, as the only label |
| Higher rate first | Pay the higher APR first | Avalanche |
| Smaller balance first | Pay the smaller balance first | Snowball |
| Use this scenario in my plan | Copy a decision-lab row onto the books | Apply this row |
| Bank link | Optional Plaid connection | Sync, in primary buttons |
| Erase everything | Delete the on-phone books and secrets | Reset |
